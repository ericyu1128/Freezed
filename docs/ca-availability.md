# Canadian availability

Generated by `npm run availability:report` from `data/prices.json` (price check on 2026-11-04). For each of the 51 matchable items: how many of the 5 Canadian retailers (Evo Canada, Sport Chek, Sporting Life, Altitude Sports, MEC) carry it, sorted lowest first.

"Carries" means the check **found** the exact current model at a clear price. "Ambiguous" means a likely listing that couldn't be confirmed. Those shops still appear on the card as "Check price →", so they don't count as carrying it here. Details for every cell are in `docs/price-check-2026-11-04.md`.

"Top pick" counts how many of the 864 questionnaire profiles (every activity × gender × level × style × temperature × budget, as in the tests) get this item as their #1 for its category. Ranking never reads prices or availability, so these counts don't change when stock does.
